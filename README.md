# Netflix Clone

Welcome to the **Netflix Clone** project! This project is a front-end web application replicating the look and feel of Netflix, showcasing skills in HTML, CSS, JavaScript, and React.

## Overview
- **Project Overview**: This Netflix Clone is a responsive web application designed to replicate the core UI and functionality of Netflix. It fetches data from TMDB (The Movie Database) API to display movie categories, banners, and trailers dynamically.
- **Objective**: Recreate the Netflix user interface to practice front-end development and API integration.
- **Dataset/API**: TMDB API

## Features
- **Responsive Design** – Works seamlessly on mobile, tablet, and desktop.
- **API Integration** – Fetches movie data dynamically.
- **User Authentication** – Simulated login functionality.
- **Dynamic Banners** – Auto-rotating featured content.
- **Hover Effects** – Interactive elements on hover.
- **Genre Rows** – Categorized movies by genre.
- **Search Functionality** – Ability to search for movies.

## Technologies Used
- **Frontend**: HTML, CSS, JavaScript
